# Einstein Engine

Real special- and general-relativity calculations using standard textbook
equations. This engine follows **NEWTONS** (constellation standard).

## Physics scope

- Lorentz factor (special relativity)
- Time dilation
- Mass–energy equivalence (E = mc²)
- Relativistic momentum
- Schwarzschild radius (non-rotating black hole)

Constants use CODATA 2018 values for the speed of light and gravitational
constant.

## Validation

The engine includes real-world reference checks:

- Lorentz factor at v = 0.8c → 1.666667
- Sun Schwarzschild radius → ~2953 m
- Earth Schwarzschild radius → ~8.87 mm

## Usage

```bash
javac einstein/engine/EinsteinEngine.java
java einstein.engine.EinsteinEngine
```
